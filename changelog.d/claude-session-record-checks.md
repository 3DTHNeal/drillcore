### Added

- `[[proof.record_logs]]` takes `sessions`, a folder of an AI assistant's own session transcripts (Claude Code's JSON Lines files, one per session), and `proof`'s `records` check then holds the log and the record to what was typed. Each prompt typed in a session, messages queued while the assistant was busy among them, must be in the log or a cuts file word for word; a session none of whose prompts is there is reported once, as one with no entry. A message that quotes the assistant first and then answers counts as logged when its answer is. Each prompt the record quotes on a prompt or follow-up line must be the whole of a typed message, or mark its cuts with "…" or a bracketed note: a quotation of only part of one fails, and so does one message given as two quotations. What the app or the assistant wrote into a session (a block in angle brackets, a summary written when its context was compacted, the note an interruption leaves) isn't a prompt, and a message a forked session copies counts once.
